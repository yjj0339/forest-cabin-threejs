# 霖林小屋 · Forest Cabin

THREE.js 三维森林小屋场景。

## 特性
- 森林小屋（木屋、门窗、烟囱）
- 树上小动物（小鸟、松鼠）
- 小屋前方向日葵花田 + 低矮杂草
- 飞舞的蝴蝶与蜜蜂
- 6 种天气/时光切换：晴天、雾天、日落、夜晚、雨天、黎明
- 手机友好：触摸旋转、双指缩放

## 使用
1. 在仓库 Settings → Pages 中，选择 Source: Deploy from a branch → Branch: main / (root) → Save
2. 等待几十秒后访问：https://yjj0339.github.io/forest-cabin-threejs/

手机浏览器直接打开上述链接即可使用。
